You receive the full conversation. Reply with JSON only (no markdown fences),
exactly this shape:
{{
  "errors": [
    {{
      "you_said": "her english is not so much good",
      "correct_form": "her English isn't very good",
      "error_type": "quantifier_modifier",

    }}
  ],
  "did_well": "one specific thing, not generic praise",
  "summary": "two sentences about what the conversation was about and how it went"
}}

Rules for errors:
- error_type must be one of the supplied codes. Never invent one.
- you_said quotes ONLY the wrong fragment, VERBATIM from something the learner
  actually wrote in this conversation. Never a paraphrase, never your own words,
  never a sentence you wrote. If you cannot quote it exactly, leave it out.
- Maximum 2 errors — the ones that most matter. Prefer fewer. Zero is valid when
  the conversation is clean.
- correct_form must use the most natural, common phrasing a fluent speaker
  would actually use.
- explanation: max 25 words, English.

Rules for did_well:
- Always present. Name one concrete thing the learner got RIGHT.
- Never restate an error. Never generic praise like "Good job."

Rules for summary:
- Two sentences, plain English, written ABOUT the conversation rather than to
  the learner. It is a note the app keeps for itself.
- Say what was talked about and how the conversation went.
- Never quote the learner. Never list their mistakes again. Never a score, a
  count, a percentage or a grade.
- Never say the learner failed, missed, or got something wrong. Never a
  disappointed emoji.
